STEP 1

Bridge Model Builder

From the analysis model to buildable pieces.

  • Import an S-FRAME .TEL file
  • Group sticks into members, checked against the member box
  • Add laterals, struts and X braces between the trusses
  • Set every joint: EW or SLOT, bolts, yard or site
  • Type in the construction site and check the fit
Open the builder → STEP 2

Sequence Studio

Plan the build on the site, stage by stage.

  • Open a bridge file and a construction site
  • Group pieces into lifts and stages
  • Play the build and scrub through it
  • Timing, builders and checks are on the way

Good to know

Your work is saved in your own browser on each computer. To share it, download the bridge, site or sequence file and pass it on, or commit it to this repository. After the first visit the tools also work without internet; in Chrome or Edge, “Install app” in the address bar adds them like a desktop app.
